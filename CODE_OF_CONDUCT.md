# Code of Conduct

## Our Standards

Be respectful, specific, and constructive. Discuss technical decisions without personal attacks. Harassment, discrimination, threats, doxxing, and publication of private information are not acceptable.

## Scope

This policy applies to repository issues, pull requests, discussions, security reports, and other spaces represented as part of this project.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Do not include sensitive personal information in a public issue. The maintainer may edit, remove, lock, or reject contributions and may temporarily or permanently restrict participation when necessary to protect the project community.

Enforcement decisions should consider context, impact, prior behavior, and the safety of affected people.
